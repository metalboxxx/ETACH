# 22.3.6 waiver

This waiver covers R22.3.6.4, the GPU check of typed files as text and sentence openings, which failed on both
files (`docs/initial-plan/phases-testing/step22.3-plan.md` §6, 2026-10-19).

1. **Typed PDF through the text path.**
   - Target: the structure is correct when a typed PDF page goes to the model as text.
   - Result: national exam test 5 came out wrong: options became sections, questions 13–14 were missing, and
     rewrite questions lost their sentences. Reading the same test from images did better.
   - Deferred to: the extraction-quality plan (`docs/initial-plan/plan-extraction-quality.md`), after step 22.
   - Accepted by teacher: Teacher

2. **Opening words (`answer_start`).**
   - Target: extraction keeps a rewrite's printed opening words, so its key gets all four forms.
   - Result: no opening words were kept, on either the text path or the image path. The workaround is to type a
     "Start: …" line on the test page.
   - Deferred to: the extraction-quality plan, after step 22.
   - Accepted by teacher: Teacher

Shipped in 0.4.0 to judge in real use; models can be changed in the model manager.
