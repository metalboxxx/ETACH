## 1. Rules for agents

0. **Write scope.** Each step may write **only** the paths §6 lists for it; everything else is read-only for that agent. The verifier checks `git diff --name-only main..<commit>` against §6, and a file outside the scope is a failure. If the work needs a path outside its scope (for example a bug in an earlier step's module), the agent **stops and asks the orchestrator**. The orchestrator's own commits to `docs/structure.md` on a step branch are outside this check.
1. **Build only at the paths in this map.** Inside a folder marked `*` (e.g. `repos/*.py`), adding modules is free. Any other new file outside the map, a new folder, a new package, or a rename → **stop and ask the orchestrator**, who updates this map first.
2. **Tests mirror the source:** `src/etach/<pkg>/<mod>.py` → `tests/unit/<pkg>/test_<mod>.py`. Test helpers go in `tests/support/`, never in `src/`.
3. **Generated folders are never hand-edited:** `sidecar/schema/` (`etach schema export`, `etach openapi export`) and `app/src/gen/` (`npm run gen:types`).
4. **No hard-coded data paths.** Every path the app reads or writes is resolved through `etach.appdir` (sidecar) or `paths.rs` (shell), relative to the app folder (PRD §11). Tests use `tmp_path`.
5. **`domain/` is pure** (no database, network or file I/O), except `domain/merge.py` and `domain/review.py` (the step 10 services, which call `store/`) and `export_schemas()` in `domain/__init__.py` (writes `sidecar/schema/`; the rendering `render_schemas()` stays pure).
6. **`cli.py` only parses arguments** and calls a function in the package that owns the command.
7. **Model tags appear only in `llm/defaults.py`** (S4).

## 7. Cross-step conventions (decided by the orchestrator; binding for later steps)

| Topic | Convention | Set in |
|---|---|---|
| IDs | Readable `T-/S-/A-` + 4 digits (next = max+1) for teacher-visible rows; **monotonic** ULIDs (`store.db.new_ulid`) for internal rows, so `ORDER BY created_at, id` is insertion order | 2 |
| Time | ISO-8601 UTC strings in the DB; timezone-aware datetimes in pydantic | 1, 2 |
| DB access | stdlib `sqlite3`, sync; async code calls it via `asyncio.to_thread`, one connection per thread at a time; `transaction()` nests with savepoints | 2 |
| Key change | "A key change" (which deletes that question's explanations) = `accepted` changed. A status-only change keeps them | 2 |
| Files | Content-addressed, never modified; a dedup hit keeps the first row's `kind` and refreshes `created_at` | 3 |
| Rotation | Degrees **clockwise**. Derived images apply the EXIF transpose first, then the teacher's rotation (the photo check shows EXIF-corrected images) | 3 |
| Page size | PDFs are rasterized at 200 dpi; `prepare_pages` (step 9) resizes every page to max 1600 px | 3 |
| Inputs | JPEG, PNG, WebP, PDF, DOCX. HEIC and `.doc` raise `UnsupportedDocument` | 3 |
| Confidence | `etach.llm.confidence`: enum margin = p(chosen) − p(best other valid choice), clamped at 0; multi-token enum values (e.g. `circled_option`) use the min token prob; free text = min token prob. Pass the **same JSON Schema the model was given**. Fallback `None` = `none`; every fallback result is `low_trust` | 6 |
| Runtime | Nodes are wrapped with `runtime.steps.step(node, fn, item=...)`; pass `steps.current_step_id()` to `client.call`. The `OllamaClient` gets its **own** DB connection (not the RunManager's).
